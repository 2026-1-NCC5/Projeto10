## O que é

Sistema de visao computacional que usa **YOLOv8** para detectar e contar automaticamente pacotes de alimentos doados (arroz, feijao, acucar, cafe, macarrao) em tempo real via webcam. Cada deteccao e vinculada a equipe arrecadadora e registrada com evidencia fotografica.

O sistema substitui a contagem manual do LE por um pipeline automatizado: camera → modelo IA → banco de dados → dashboard web.
